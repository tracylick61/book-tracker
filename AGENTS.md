# Правила работы с Book Tracker

- Это персональный сервис чтения и книжный дневник, а не магазин или маркетплейс.
- Перед любыми UI-изменениями прочитай `DESIGN.md` — источник истины для визуального дизайна.
- Сохраняй стек React + TypeScript + Vite и существующую архитектуру, если задача не требует иного.
- Не используй Tailwind, Shadcn и другие UI-библиотеки без явного запроса.
- Не добавляй backend, API и внешние интеграции без отдельной задачи.
- Сохраняй существующие сценарии: главная, библиотека, цитаты, детали книги, добавление, редактирование, удаление, прогресс и заметки.
- Сохраняй localStorage `book-tracker-library` и обратную совместимость старых книг без `quotes` и `notes`.
- Интерфейс, подписи, ошибки, пустые состояния и доступные имена элементов должны быть на русском. Пользовательский контент не переводить автоматически.
- После изменений запускай `npm run lint` и `npm run build`; исправляй ошибки и проверяй `git diff --check`. Для UI также проверяй затронутые сценарии и ширину 1024 px.
